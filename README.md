## Description
This repository contains solutions for Lab 4b, focusing on creating valid JSON datasets, retrieving data using the native JavaScript `fetch()` API, and implementing DOM manipulation using jQuery.

## Setup and Run Instructions
1. **Question 1 & 2 (`books.json` and `books.html`):** 
   - Open the project folder in VS Code.
   - Right-click `books.html` and select **Open with Live Server** to bypass CORS restrictions and allow the `fetch()` API to read the local JSON file. 
   - *Do not open the file directly in the browser (file://).*
2. **Question 3 (`jquery-dom.html`):**
   - Double-click `jquery-dom.html` to open it directly in any modern web browser.
   - Click the "Click me" button to test the jQuery event listener.
